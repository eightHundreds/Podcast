# 设计数据密集型应用

围绕《Designing Data-Intensive Applications》（DDIA）的系列播客。

从「云原生分布式 vs 单机极简」谈起，梳理架构权衡、数据模型与存储选型背后的取舍逻辑，把书里的原则接到真实系统设计决策上。
